# Resistor Color Code Calculator

A simple Python GUI project to calculate resistor values using color codes.

## Features

* Select resistor color bands
* Calculate resistance value
* Display tolerance
* Shows resistor bands visually

## Technologies Used

* Python
* Tkinter

## How to Run

Run the following command:

```bash
python resistor.py
```

## Example

**Red - Violet - Yellow - Gold**

**270 kΩ ±5%**
